# Gestion Concessionnaire

Application Java de gestion d'un concessionnaire automobile.

## Fonctionnalités
- Gestion des véhicules (Berline, Citadine, SUV, Camionnette)
- Gestion des clients et du personnel
- Gestion des ventes, achats et locations
- Gestion des fournisseurs

## Technologies
- Java
- NetBeans (Ant)
- POO (Héritage, Polymorphisme)

## Lancer le projet
1. Ouvrir le projet dans NetBeans
2. Run (F6)
